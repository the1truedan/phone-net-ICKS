# Examples

`case-job-history.example.html` is the job-history report from one real case, made public-safe:
counts, coverage, queue order and progress, timing, the consent/procedure log and the government sources are real;
people, organizations, places, phone serials, document titles and paths are replaced by roles and categories, and a final
redaction pass (`stack/jobboard/redact_file.py` with a local, git-ignored term list) blocks out anything left (█).

Rows marked ⚖ are the processing queues whose results led to incidents or statements for a lawyer to check,
with the party's role (care-plan manager / payroll agent).
