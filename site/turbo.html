Tethered USB Rapid Bulk Offload. A phone pull starts over Wi-Fi. Before every file the script checks for the USB-C cable; the moment the phone is plugged in, the rest of the pull moves to the cable, and if it is unplugged the pull goes back to Wi-Fi (finding the phone's new Wi-Fi port on its own). Every file is still checked against the phone's own SHA-256, and the log and the phone's progress page show the mode with this file's speed and the average.
