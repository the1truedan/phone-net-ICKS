🧪 Example: Sam and Grandma Rose

Sam is a made-up caregiver. Grandma Rose is made up too. Nothing on this page is a real person, date or record. It shows the order of steps, which tool does each one, and where a person stays in charge.

What Sam did

  1. Plugged in the phone and copied only what was new.
  2. Opened Grandma Rose's patient portal and pharmacy app himself; the app saved each screen he opened.
  3. Let the computer turn voice notes into text overnight.
  4. Asked plain questions and opened the cited file before using any date.

What the app never did

  • Type a password, sign, submit or send.
  • Upload anything. Every step ran on Sam's computer.
  • Change or delete an original file.
